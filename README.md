# Plataforma ERP — Pecuaria Real Victoria (Ramari)

Plataforma web para capturar y consultar la operación de la empresa: planta de alimentos, finanzas, cerdos, aves, ganado, borregos, berries, almacén, gastos y nómina.

Tecnología: Supabase (base de datos y usuarios) + Vercel (página web).

Fase actual: 0 (base) y 1 (planta de alimentos).
